1. 🖥️ What is a Computer?

A computer is an electronic machine that receives data, processes it according to instructions, stores information and produces useful results.

Simple Example

Input → Processing → Output → Storage
  • Input: You type something on the keyboard.
  • Processing: The processor works on the data.
  • Output: The result appears on the monitor.
  • Storage: The information can be saved on SSD, HDD or another storage device.

Where are computers used?

  • Schools and education
  • Offices
  • Banks
  • Hospitals
  • Government services
  • Businesses
  • Science and research
  • Communication
  • Entertainment
  • Programming and software development

2. ⚙️ How a Computer Works

A computer works by combining hardware and software. Hardware is the physical equipment and software consists of programs and instructions.

Stage Meaning Example
Input Data enters the computer. Typing with keyboard
Processing CPU processes instructions. Calculating numbers
Output Computer shows the result. Monitor displays result
Storage Data is saved for later use. Saving a document

4. 🧠 CPU and Processor

CPU means Central Processing Unit. It performs many of the calculations and instructions required by programs.

Important CPU concepts

  • Processor cores

  • CPU architecture

Important: A higher CPU specification does not automatically mean that every computer task will be faster. Performance depends on the complete system and workload.

5. 💾 RAM, ROM and Storage

RAM

RAM is temporary working memory used while programs are running. When the computer is powered off, normal RAM contents are lost.

ROM

ROM refers to non-volatile memory traditionally used for firmware and other fixed instructions.

HDD

A Hard Disk Drive stores data magnetically on spinning disks.

SSD

A Solid State Drive uses flash memory and generally provides much faster access than traditional HDDs.

Type Main Purpose
RAM Temporary working memory
SSD Fast permanent storage
HDD Permanent storage
USB Drive Portable storage

8. 🖱️ Mouse — Complete Beginner Guide

Mouse is a pointing device used to move the pointer on the screen and interact with buttons, files, folders and programs.

8.1 Move the Mouse

Step 1: Place the mouse on a flat surface.
Step 2: Move the mouse slowly.
Step 3: Watch the pointer move on the screen.

8.2 Single Left Click

Move the pointer over an item and press the left mouse button once.

A single click is commonly used to select an item or activate a button.

8.3 Double Click

Step 1: Move the pointer over a file, folder or application.
Step 2: Quickly press the left button two times.
Result: The selected item may open.

8.4 Right Click

Press the right mouse button once to open a context menu for the selected item.

8.5 Mouse Wheel

  • Scroll upward
  • Scroll downward
  • Navigate long pages

8.6 Drag and Drop

Step 1: Place the pointer on an item.
Step 2: Press and hold the left button.
Step 3: Move the mouse to the destination.
Step 4: Release the button.

8.7 Selecting Multiple Files

Hold Ctrl while clicking individual files to select multiple separate items.

For a continuous group of files, click the first item, hold Shift, then click the last item.

10. 🪟 How to Open and Control a Window

Open a window

Step 1: Find the application or folder.
Step 2: Double-click its icon with the left mouse button.
Step 3: The application or folder window will open.

Minimize

Click the minimize button to temporarily hide the window while keeping the program open.

Maximize

Click the maximize button to expand the window to the available screen area.

Restore

Restore returns a maximized window to a smaller resizable window.

Close

Click the X button in the window's title bar to close it.

Switch between open applications

Use: Alt + Tab

Hold Alt and press Tab to move between open windows.

11. 📁 Files and Folders

What is a file?

A file is a stored unit of information such as a document, photograph, video, audio recording or program.

What is a folder?

A folder is used to organize files and other folders.

Create a new folder

Step 1: Open the location where you want the folder.
Step 2: Right-click an empty area.
Step 3: Choose New → Folder.
Step 4: Enter a name.
Step 5: Press Enter.

Open a folder

Move the mouse over the folder and double-click the left mouse button.

12. 📋 How to Copy a File

Mouse method

Step 1: Find the file.
Step 2: Right-click the file.
Step 3: Select Copy.
Step 4: Open the destination folder.
Step 5: Right-click an empty area.
Step 6: Select Paste.

Keyboard method

Step 1: Select the file.
Step 2: Press Ctrl + C.
Step 3: Open the destination folder.
Step 4: Press Ctrl + V.
Important: Copy creates another copy of the item. The original normally remains in its original location.

13. ✂️ Cut and Move Files

Cut is normally used when you want to move an item from one location to another.

Step 1: Select the file.
Step 2: Press Ctrl + X.
Step 3: Open the destination folder.
Step 4: Press Ctrl + V.

The same operation can normally be performed through the right-click menu using Cut and Paste.

14. 🗑️ Delete and Restore Files

Delete a file

Step 1: Select the file.
Step 2: Press Delete or use the right-click menu.
Step 3: Check the confirmation if shown.

Restore from Recycle Bin

Step 1: Open Recycle Bin.
Step 2: Find the deleted item.
Step 3: Right-click it.
Step 4: Choose Restore.
Warning: Permanently deleted files may be difficult or impossible to recover. Important data should always have a backup.

15. ✏️ Rename Files and Folders

Method 1: Right-click the file → Rename → type the new name → Enter.
Method 2: Select the file and use the Rename command available in File Explorer.

Be careful when changing file extensions because an incorrect extension can prevent a program from recognizing the file correctly.

21. 🔐 Computer Security

Strong passwords

  • Use long, unique passwords.
  • Avoid using the same password everywhere.
  • Use a password manager when appropriate.
  • Enable multi-factor authentication where available.

Phishing

Phishing attempts try to trick users into revealing passwords, financial information or other sensitive data.

Malware

Malware is malicious software designed to damage, disrupt, spy on or gain unauthorized access to systems.

Safe computer habits

  • Keep the operating system updated.
  • Use trusted software sources.
  • Do not open unexpected attachments.
  • Check website addresses carefully.
  • Use security software where appropriate.
  • Back up important information.

22. 💽 Backup and Data Protection

A backup is an additional copy of important information kept so that data can be recovered after accidental deletion, hardware failure or another problem.

Possible backup locations

  • External hard drive
  • External SSD
  • USB storage
  • Network storage
  • Cloud storage
Important files should not exist in only one location. Regularly check that backups can actually be restored.

24. 🛠️ Troubleshooting

Computer is slow

  • Check which applications are running.
  • Close unnecessary programs.
  • Check available storage.
  • Restart the computer.
  • Install important system updates.
  • Check for suspicious software.

Mouse is not working

  • Check the cable or wireless connection.
  • Try another USB port.
  • Replace or recharge batteries if applicable.
  • Restart the computer.

Keyboard is not working

  • Check the connection.
  • Try another USB port.
  • Check wireless batteries or connection.
  • Restart the computer.

Internet is not working

Step 1: Check Wi-Fi or Ethernet connection.
Step 2: Check the router/modem.
Step 3: Try another website.
Step 4: Restart the network connection if needed.
Step 5: Contact the internet provider if the service remains unavailable.

Program has frozen

Give the program a moment if it is busy. If it remains unresponsive, use the operating system's task-management tools to close it, keeping in mind that unsaved work may be lost.

25. 🚀 Advanced Computer Knowledge

Operating System

The operating system manages hardware, applications, files, users and many system resources.

File Extensions

File extensions commonly indicate the type of file, such as documents, images, audio, video or executable programs.

Drivers

Device drivers allow the operating system and hardware devices to communicate properly.

BIOS and UEFI

Firmware such as BIOS or UEFI initializes hardware and helps start the operating system.

Graphics Processing Unit

A GPU is specialized hardware used for graphics and parallel workloads. It may be integrated into the processor or provided as a separate graphics card.

Cloud Computing

Cloud computing provides computing resources and services through network-connected systems.

Programming

Programming is the process of creating instructions that computers can execute. Common programming languages include Python, JavaScript, Java, C, C++ and many others.

Database

A database is an organized system for storing and retrieving structured information.

Artificial Intelligence

Artificial intelligence refers to computer systems designed to perform tasks that normally require aspects of human intelligence, such as recognizing patterns, understanding language or making predictions.
